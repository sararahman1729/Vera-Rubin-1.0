# Vera-Rubin-1.0
What is Vera Rubin Observatory: The Vera C. Rubin Observatory (formerly the Large Synoptic Survey Telescope) is an astronomical facility on Cerro Pachón in northern Chile. It conducts the Legacy Survey of Space and Time (LSST), a 10-year project that repeatedly photographs the southern sky to create an ultra-wide, high-detail time-lapse record of the universe.
